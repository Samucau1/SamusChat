# Logo e ícones SamusChat

A marca SC branca no degradê roxo corresponde à logo do trailer. O SVG usa contornos vetoriais; não depende de fontes instaladas.

- `samuschat-logo.svg`: matriz vetorial, 1024 × 1024.
- Web: favicon SVG/ICO, ícone Apple Touch e manifesto com PNGs de 192/512 px.
- Windows: `samuschat-desktop/public/icons/samuschat.ico`, com tamanhos de 16 a 256 px.
- Android: launcher adaptativo com fundo em degradê, letras em vetor e versão monocromática para ícones temáticos no Android 13+. PNGs de compatibilidade em todas as densidades usuais.

O desktop atual é a aplicação web. No Edge/Chrome, use a opção de instalar o SamusChat como aplicativo para obter uma janela própria e o ícone no sistema. O manifesto não oferece funcionamento offline; chat e login continuam exigindo conexão.

O Android recebe o ícone ao instalar/atualizar um APK compilado com estes recursos. Um APK já instalado não muda apenas com a implantação do servidor.
