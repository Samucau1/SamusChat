# Capturas do SamusChat

[← Apresentação do projeto](../../README.md)

Imagens reais das interfaces, utilizadas na apresentação e nos guias. As capturas podem registrar etapas diferentes do desenvolvimento; os relatórios associados informam o cenário validado.

| Imagens | Origem |
| --- | --- |
| `login.png`, `servers.png`, `chat.png` | Telas Android com contas de demonstração |
| `validacao-midia-2026-10-08/` | Validação de chamadas e transmissão em dois emuladores; [relatório](../REGRESSAO_MIDIA_ESTABILIDADE_2026-10-08.md) |
| `desktop/chat-desktop.png` | Interface real do navegador, capturada em 09/10/2026 em 1440 × 900; API H2 descartável, três contas fictícias, dois servidores e sete mensagens de apresentação |

A captura desktop foi feita com o canal conectado por STOMP e sem utilizar contas pessoais ou o PostgreSQL de desenvolvimento. Os diálogos foram preparados para mostrar o layout; a captura complementa os testes registrados, sem representar uma nova regressão completa.
