# SamusChat para Android

[Baixar SamusChat 1.4.3 beta](https://github.com/Samucau1/SamusChat/raw/refs/heads/deploy/render-free-beta/releases/android/SamusChat-1.4.3-beta.apk)

- Android 8.0 ou superior.
- Versão 1.4.3-beta, código 10, pacote `com.samuschat`.
- Servidor: https://samuschat-beta.onrender.com/.
- Instalação beta assinada com a mesma chave de desenvolvimento usada no APK já instalado nos testes.
- Não contém login ou senha de conta incorporados. Cada pessoa entra ou cria sua própria conta.

Baixe o APK no celular, abra o arquivo e confirme a instalação. Se solicitado, autorize a instalação pelo aplicativo usado para abrir o arquivo. Para atualizar uma instalação assinada com a mesma chave, instale por cima, sem desinstalar o aplicativo.

Depois de instalado, o acesso depende da internet do celular e da disponibilidade do servidor. O serviço gratuito pode demorar no primeiro acesso após ficar inativo.

O arquivo `SHA256SUMS.txt` permite conferir a integridade do download. No PowerShell: `Get-FileHash .\SamusChat-1.4.3-beta.apk -Algorithm SHA256`.

O código desta versão passou por compilação das variantes debug e validation, lint e 70 testes unitários, sem falhas. O APK é o mesmo disponibilizado no teste do Moto G7 Play.
