# SamusChat Desktop

Protótipo local em TypeScript, React e CSS, organizado em MVC. Dados fictícios; mensagens e perfil ficam em memória até recarregar. Backend e instalador ainda não estão integrados.

```powershell
npm ci
npm run dev
```

Abra o endereço informado pelo terminal. `npm run build` verifica os tipos e gera `dist/`; `npm run preview` serve o build localmente.

Veja o [plano, tecnologias, entradas e arquitetura](../docs/DESKTOP_MVC.md).
